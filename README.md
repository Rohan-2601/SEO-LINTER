# 🔍 seo-lint-cli  
A simple, fast, developer-friendly **SEO Linter** for static HTML builds and live URLs.

Think of it as **ESLint for SEO hygiene** — it does **not generate SEO**, it **prevents SEO mistakes** before deployment.

---

## 🚀 Features

- Works with **any frontend framework**
- Flags real SEO issues developers often miss
- Scans:
  - Local build folders (`dist/` or `build/`)
  - Single live URL (`--url`)
  - Multiple URLs (`--urls file.txt`)
- Zero configuration required
- Developer-friendly output
- Never blocks deployment (warnings only)
- Lightweight (Node.js + Cheerio)
